===================================================================
     PROJECT GUIDANCE & TEAM PORTAL - QUICK START GUIDE
===================================================================

IMPORTANT STEP 1: EXTRACT THE ZIP FILE!
Do NOT run files directly from inside the ZIP file.
1. Right-click "Project-Guidance-Team-Portal.zip"
2. Choose "Extract All..." and click Extract.
3. Open the newly extracted folder.

-------------------------------------------------------------------
STEP 2: MAKE SURE NODE.JS IS INSTALLED
-------------------------------------------------------------------
This is a full-stack Node.js + React web application.
Node.js is required to run the server.
If you do not have Node.js installed on your computer:
👉 Download and install the free LTS version from: https://nodejs.org

-------------------------------------------------------------------
STEP 3: START THE APP (1-CLICK)
-------------------------------------------------------------------
Inside the extracted folder, simply double-click:
👉 "START-PORTAL.bat"

It will automatically:
- Verify your Node.js environment
- Install any missing packages
- Start the server
- Automatically open your browser at: http://localhost:5000

-------------------------------------------------------------------
MANUAL START VIA TERMINAL (ALTERNATIVE):
-------------------------------------------------------------------
1. Open Command Prompt / Terminal in this folder
2. Run:
      cd server
      npm install
      npm start
3. Open your browser and go to: http://localhost:5000
